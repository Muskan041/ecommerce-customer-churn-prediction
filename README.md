# E-commerce Customer Churn Prediction

An end-to-end data science project designed to analyze customer behavior and predict churn risk for an e-commerce platform using machine learning.

## 📌 Project Overview
Customer churn is a critical metric for e-commerce businesses. Acquiring new customers is often significantly more expensive than retaining existing ones. This project leverages machine learning to identify high-risk churn customers early, allowing marketing and support teams to take proactive retention measures.
